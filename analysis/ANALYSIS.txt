PocketTopo 1.372 — local decompilation, 2026-10-09

RESULT
The entire main EXE was processed into C# and IL using ILSpyCmd 9.1.0.7988.
Decompilation completed with exit code 0 and no diagnostics. The result
contains 56 C# files, 15,469 lines, 73 types, and 849 methods: 829 with IL
bodies, 16 abstract methods, and 4 native imports from coredll.dll. All four
localization assemblies (de, fr, pl, sl) were also processed without diagnostics.

This is a reconstruction from a compiled program, not the author's original
project. The recovered project has not been recompiled or fully tested for
compatibility. The observations below come from code analysis, not new
behavioral tests. Earlier native ID tests remain documented in PR #136.

SPECIFIC CODE OBSERVATIONS
1. DataSet.Load includes other *.top files from ActualDirectory() as
   templates before reading the current file. Geometry comparisons must
   therefore also control the contents of the opened file's directory.
2. Trip.Read interprets -32768 as Auto mode and resets declCorr to zero.
   Trip.GetDeclination in the standard version 1.372 returns the supplied
   decl without using auto, date, or rf. This path does not calculate a
   correction from date and location. This finding does not establish the
   behavior of the Swiss version 1.472.
3. Survey.EvalData groups consecutive measurements of matching station
   pairs, including pairs in the reverse direction. It calculates average
   geometry from vector components, accounting for the sign of reverse
   measurements and integer arithmetic. Do not assume equivalence to
   averaging lengths and angles separately.
4. Loop.Close distributes the correction among components in proportion
   to dist. Loop.CloseLoops repeats corrections until the largest error
   component is <= 10 internal units (mm); the constant IT_LIMIT=10 is an
   error threshold, not a limit on the number of iterations.
5. ID.cs explicitly confirms LIMIT=-1048576, RESVD=-256, and the offset
   2146435071 used during reading and writing. ToString hides reserved
   values. ID equality still compares the internal value — an empty string
   does not eliminate all internal differences. Different aspects of
   compatibility (export text, grouping, geometry) must be tested separately.

LIMITATIONS
The author's comments, project history, some local variable names, and the
original source organization have not been recovered. The coredll.dll
imports contain declarations only; the system implementation and DistoX
firmware are not part of this EXE. Bluetooth and hardware calibration
require separate tests on the device. Successful decompilation does not
confirm the semantic equivalence of a recompiled application.
